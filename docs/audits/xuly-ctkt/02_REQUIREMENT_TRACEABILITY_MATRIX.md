# 02 — Requirement Traceability Matrix

Đường dẫn backend tương đối `gateway/src/Aiq.Gateway/`; frontend `web/src/`; agent `agent/`.

**Bằng chứng:**
- STATIC = đã đọc source.
- TEST = đã chạy test trong lần audit này, trên DB Postgres **cô lập** (`aiq-audit-pg`, mạng `aiq-audit-net`, tmpfs).
- LIVE = chạy trên môi trường thật.
- NOT VERIFIED = chưa có bằng chứng.

**LIVE trong lần audit này: không thực hiện.** Quy tắc cấm ghi DB live và đổi mật khẩu; mọi luồng đều cần đăng nhập và ghi dữ liệu → **BLOCKED**.

Trạng thái: PASS / PARTIAL / MISSING / INCORRECT / NOT TESTED / PDF UNCLEAR.
