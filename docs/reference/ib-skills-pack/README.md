# 21 Claude Skills for Investment Banking Deal Execution

An install-on-demand skill set that runs Claude through the same backbone an execution
team uses on a mandate: Originate, Value, Model, Diligence, Execute, Communicate. The 21
skills below take a deal from sector screen to investment-committee recommendation, each
naming the generic technique it uses, the steps it follows, and the deliverable it produces.

## What's inside

1. **Sector Screen Mapping** - Screens a sector against quantitative and qualitative filters to produce a ranked shortlist of candidates, used at the very start of origination when deciding where to focus pitch effort.
2. **Buyer Acquirer Lists** - Builds and segments a curated list of likely strategic and financial counterparties for a given asset, used once a mandate or thesis exists and you need to know who would actually transact.
3. **Thesis Angle Development** - Develops a crisp deal thesis and value-creation angle from screening and buyer-list inputs, used when raw research must become a persuasive reason this deal should happen now.
4. **DCF Valuation** - Builds a discounted-cash-flow valuation with transparent cash-flow, discount-rate, and terminal-value assumptions, used when the team needs an intrinsic, assumption-driven view of value.
5. **Comparable Companies** - Runs a comparable companies analysis by selecting peers, calculating trading multiples, and applying them to the target, used for a current, market-anchored valuation view.
6. **Precedent Transactions** - Performs precedent transaction analysis by assembling comparable deals, computing transaction multiples, and applying them to the target, used to capture control premia and real-world pricing.
7. **LBO Analysis** - Builds a leveraged-buyout analysis to test sponsor ability-to-pay and returns under a financing structure, used to set the floor or financial-buyer view in a valuation range.
8. **Three Statement Build** - Builds an integrated three-statement model where the income statement, balance sheet, and cash flow flow link and balance, used as the forecasting backbone for every downstream valuation.
9. **Sensitivity Tables** - Builds live one- and two-variable sensitivity tables on the model's key outputs, used to show which assumptions drive value and where outcomes break.
10. **Scenario Toggle Design** - Designs a scenario framework with a single toggle that drives base, upside, and downside cases through the model, used to present coherent alternative outcomes cleanly.
11. **Model Audit Review** - Audits an integrated model for circularity, broken links, hardcodes, and formula inconsistencies, used as the quality gate before a model goes upstairs.
12. **Data Room Synthesis** - Synthesizes a large data room into an organized index, thematic summaries, and a gap list, used to make thousands of documents navigable and decision-ready.
13. **Earnings Quality Review** - Reviews the quality of reported earnings by testing add-backs, normalizing run-rate, and checking cash conversion, used to separate sustainable earnings from accounting noise.
14. **Risk Flag Register** - Consolidates diligence findings into a ranked risk register scored by severity and deal impact, used to focus the team and committee on what actually matters.
15. **CIM Drafting** - Drafts a confidential information memorandum that frames the company, market, and financials into a buyer-ready narrative, used to market an asset and solicit indications of interest.
16. **Management Presentation** - Builds the management-presentation deck and supporting talking points used in live buyer meetings to reinforce the equity story and handle scrutiny.
17. **Process Letter Drafting** - Drafts the process letter that sets bid instructions, required terms, and the timeline for buyers, used to keep a competitive process orderly and on schedule.
18. **Buyer Q&A Management** - Manages the buyer question-and-answer workstream by logging, prioritizing, and drafting consistent responses, used to keep diligence moving without leaking or contradicting.
19. **Deal Memo Drafting** - Drafts an answer-first deal memo that leads with the recommendation and marshals the supporting case, used to put a decision-ready document in front of a committee.
20. **Committee Recommendation** - Frames a sharp investment-committee recommendation with the decision options, conditions, and the specific approval being sought, used to drive a clean committee decision.
21. **Committee Q&A Prep** - Prepares the team for committee scrutiny by anticipating the hardest questions and drafting evidence-backed answers, used to defend the recommendation under pressure.

## How to install

You need a Claude subscription (claude.ai) or Claude Code.

- **Claude.ai Project:** create a Project, open its knowledge / files panel, and upload the
  `SKILL.md` files for the skills you want (one folder each under `skills/`). Claude uses
  them on demand when your prompt matches.
- **Claude Code:** drop the skill folders from `skills/` into `~/.claude/skills/` so they
  are available in every session.

Then ask in plain language, for example "Use the dcf-valuation skill to build a defensible
range for this target," or "Apply deal-memo-drafting to turn this analysis into an
answer-first committee memo." Install one skill, a stage, or the whole engine.
