# Deal Memo Drafting

## When to use
Reach for this when the analysis is done and the team must convert it into a document a committee can decide from. It enforces answer-first structure so the recommendation leads and every section earns its place, rather than burying the conclusion in process narrative.

## Instructions
1. State the recommendation and the headline rationale in the opening lines.
2. Lay out the situation and the deal thesis concisely beneath the recommendation.
3. Summarize the valuation conclusion and the few drivers that determine it.
4. Present the material risks and the mitigants the team relies on.
5. Move detailed support into appendices so the main memo stays answer-first.

## Example prompts
- "Draft an answer-first deal memo recommending we proceed at this valuation."
- "Write the committee memo leading with the recommendation, then the supporting case."

## Output
A deal memo with a recommendation headline, situation and thesis, valuation summary, risk section, and supporting appendices.
