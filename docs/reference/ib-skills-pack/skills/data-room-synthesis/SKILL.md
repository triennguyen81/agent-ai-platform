# Data Room Synthesis

## When to use
Use this at the start of confirmatory diligence when the volume of documents is overwhelming and the team needs structure fast. It converts an unsorted data room into a themed, indexed summary that highlights findings and, just as importantly, what is missing.

## Instructions
1. Catalogue the data-room contents into a structured index by workstream and document type.
2. Summarize each major theme (commercial, financial, legal, operational) into a short synthesis.
3. Extract and flag the findings that materially affect the deal.
4. Identify gaps and missing documents against a standard diligence checklist.
5. Draft a prioritized follow-up request list for the counterparty.

## Example prompts
- "Synthesize this data room into themed summaries and a gap list."
- "Index these diligence documents and tell me what's missing."

## Output
A synthesis pack with a document index, per-theme summaries, key-finding callouts, a gap list, and a follow-up request list.
