# Precedent Transactions

## When to use
Use this when you need to know what buyers have historically paid for similar assets, including the premium for control and partial synergies. It typically sets the upper part of a triangulated range and grounds price expectations in completed deals rather than market quotes.

## Instructions
1. Define screening criteria and assemble a set of comparable completed transactions.
2. Gather announced deal values, target financials, and consideration structure for each deal.
3. Calculate transaction multiples and implied control premia, noting market conditions at the time.
4. Apply the relevant multiple range to the target to derive an implied value range.
5. Annotate each deal's context (strategic vs financial buyer, cycle timing) that affects comparability.

## Example prompts
- "Pull precedent transactions for industrial-distribution deals over the last five years."
- "Show what acquirers paid for comparable targets and the implied premium range."

## Output
A transactions output with a deal table (multiples, premia, context), an implied-range statement, and comparability notes.
