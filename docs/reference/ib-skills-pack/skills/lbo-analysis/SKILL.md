# LBO Analysis

## When to use
Reach for this when financial sponsors are credible buyers and you need to know the price they can justify at target returns. It frames valuation from an ability-to-pay angle and complements intrinsic and market methods by anchoring what leverage and required returns permit.

## Instructions
1. Lay out sources and uses for an assumed entry price and financing structure.
2. Build the debt schedule with tranches, pricing, and mandatory and cash-sweep repayment.
3. Project the operating case and resulting cash flows available for debt service.
4. Model the exit and the equity return waterfall to compute IRR and MOIC.
5. Solve for the entry price range that meets the sponsor's return threshold.

## Example prompts
- "Run an LBO to find the max a sponsor can pay for this business at a 20% IRR."
- "Show the ability-to-pay range under a 5x leverage structure with a 5-year hold."

## Output
An LBO summary with sources-and-uses, a debt schedule, a returns table (IRR/MOIC), and an ability-to-pay range.
