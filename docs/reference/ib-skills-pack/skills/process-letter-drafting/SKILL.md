# Process Letter Drafting

## When to use
Reach for this when a round of bids is due and buyers need unambiguous instructions on what to submit, in what form, and by when. It is the document that keeps a multi-party process disciplined and the timeline enforceable.

## Instructions
1. Confirm the process stage and what the round requires from buyers.
2. Draft the bid instructions covering price, structure, and required terms.
3. Set the timeline with explicit deadlines, contacts, and submission mechanics.
4. Specify the format and supporting materials each bid must include.
5. Review for consistency with the agreed process and for fairness across buyers.

## Example prompts
- "Draft a first-round process letter for an indicative-bid deadline in three weeks."
- "Write the process letter setting bid format, required terms, and timeline."

## Output
A process-letter draft with bid instructions, required terms, a dated timeline, and submission-format specifications.
