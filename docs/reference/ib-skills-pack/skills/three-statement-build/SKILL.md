# Three Statement Build

## When to use
Use this whenever a deal needs a forecasting engine the other analyses depend on. It produces the linked statements and supporting schedules that valuation, sensitivity, and scenario work all draw from, so getting it right and balanced is the foundation of everything upstairs.

## Instructions
1. Lay out the historical statements and the driver assumptions for revenue, costs, and capital items.
2. Build the income-statement forecast down to net income from the drivers.
3. Construct supporting schedules (working capital, debt, depreciation) that feed the balance sheet.
4. Link the cash-flow statement so it reconciles net income to the closing cash balance.
5. Confirm the balance sheet balances every period and trace any imbalance to its source.

## Example prompts
- "Build a 5-year integrated three-statement model from these historicals."
- "Set up the linked statements with working-capital and debt schedules that tie out."

## Output
A three-statement model layout with linked statements, supporting schedules, a driver-assumptions block, and a per-period balance check.
